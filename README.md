# Interfaz-de-ferreter-a
Interfaz de ferretería 

Realizado por:
Sánchez Valenzuela Natalia Guadalupe
Rodriguez Andrade Denise Abigail

En este trabajo se implementó una interfaz para una ferretería orientada a computadoras de escritorio. Aquí abarcamos todas las situaciones que pueden ocurrir al momento de realizar acciones en la interfaz.
Añadimos los roles de cajeros y administradores: cada rol tiene accesos y permisos distintos, teniendo el administrador el control total del sistema y el cajero ciertas limitaciones funcionales.

Secciones y funcionalidades:
- Iniciar sesión: Control de acceso al sistema según el rol del usuario.
- Ventas: Permite buscar productos, realizar cobros, generar cotizaciones y eliminar artículos de la cuenta actual. Incluye navegación por secciones (herramientas, material eléctrico, pintura y tornillería) y una barra de búsqueda rápida.
- Devoluciones: Búsqueda de tickets, con opciones para aceptar o rechazar devoluciones con reembolso en efectivo o tarjeta.
- Inventario: Consulta de existencias con alertas visuales (por colores) para productos con stock bajo. Incluye funciones para buscar, agregar, editar y eliminar artículos.
- Clientes: Registro y gestión de clientes en la base de datos para seguimiento, otorgamiento de descuentos, ventas al mayoreo y gestión de envíos.
- Proveedores: Módulo exclusivo para administradores donde se puede agregar, editar, eliminar y consultar información esencial de cada proveedor.
- Reportes: Solo los administradores tienen acceso a esta opción. Generación automática de reportes de ventas diarias, mensuales y devoluciones, así como historial general de ventas (con fecha, hora, total, método de pago e identificador de empleado). Incluye opción de impresión.
- Usuarios: Gestión de cuentas de cajeros y administradores (agregar, editar y eliminar). Únicamente un administrador puede gestionar o eliminar a otros administradores.
- Configuración: Consulta de la versión y nombre del sistema, monitoreo de cajas activas, generación de respaldos y ajustes de preferencias (tipo de moneda, fecha y hora).
